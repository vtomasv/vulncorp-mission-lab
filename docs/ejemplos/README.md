# Ejemplo de inferencia real revisada

[inferencia-cpu.json](inferencia-cpu.json) conserva una consulta ejecutada el 20-10-2026, sus parámetros y fragmentos, respuesta original y revisión humana. Todos los datos son sintéticos. No se carga como una respuesta viva en el aula de práctica.

Antes de leer la revisión, localiza una afirmación sin sustento suficiente. Después compara tu objeción con la revisión guardada. Observa que citar un ID existente y cumplir un esquema JSON no verifica el significado de una frase.

Para obtener tu propia respuesta ejecuta `ai-prepare`, `ai-on` y una consulta desde el panel. Contrasta el tiempo de inferencia más revisión con tu análisis manual. El ejemplo no garantiza que otro equipo produzca el mismo texto o latencia.
